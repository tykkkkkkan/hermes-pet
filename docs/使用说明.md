# Hermes 桌宠 · 使用说明

> 它不是一个独立的 AI，是 **Hermes 的脸**。真正干活的是 Hermes Agent，桌宠负责把它的状态变得能看见、能摸、会说话。

## 一分钟看懂

| 问题 | 答案 |
|---|---|
| 它和 Hermes 什么关系 | 两个独立进程。桌宠每 3 秒读一次 Hermes 的状态与任务看板，把结果变成表情、气泡和通知；反过来，从桌宠拖文件、发消息，等于把活派给 Hermes |
| Hermes 关了它还活着吗 | 活着，只是变「离线」。角色还在桌面上，但聊天/派活/记忆不可用 |
| 关窗口是不是就退了 | 不是。点 × 只是收起来，进程留在托盘继续同步 |
| 怎么真正退出 | 右键角色 → 退出，或托盘右键 → 退出 |
| 开机会自己出来吗 | 开了「开机自启」就会；默认未开启时需手动 `npm start` |
| Hermes 启动会带起它吗 | 不会。只有系统登录级的开机自启，没有「跟随 Hermes 启动」 |
| 它到底有什么用 | 状态可视化、结果播报、拖文件派任务、快捷对话、语音播报、互动陪伴。**边界与未做项**见 [四阶段复盘与能力边界](./四阶段复盘与能力边界.md) |

## 一、启动与退出

```powershell
cd D:\01-项目\hermes-pet
npm start
```

- 开机自启可在右键菜单里开关（写注册表 Run 键），开了之后不用手动启动
- 退出：右键 → 退出；或在托盘图标上右键

## 二、桌面上能做什么

### 拖拽
按住角色任意位置拖动。窗口会被限制在当前显示器的工作区内，**不会拖丢**；左边拖到边界会自动停在还能抓回来的位置。

拖丢了也不怕：右键 → 「回到右下角」。

### 四个热区（点一下就响应）

| 部位 | 反应 |
|---|---|
| 头（帽子区域） | 偏头回避 + 台词 |
| 脸（眼睛附近） | 连续眨眼 |
| 身体 | 侧倾 |
| 脚 | 弹跳 |

### 悬停摸头
鼠标**停在头顶不动约半秒**，不用点——会冒三颗爱心、说一句别扭的话、头歪一下。6 秒冷却。

### 右键菜单
在弹出的独立小窗里（贴在角色侧边，不挡脸）：

| 项 | 作用 |
|---|---|
| 打开对话 | 打开聊天窗 |
| 说句话 | 让它随口说一句 |
| 回到右下角 | 窗口归位 |
| **语音播报** | 直接切换开关，右侧显示「开 / 关」 |
| **免打扰** | 直接切换开关，右侧显示「开 / 关」 |
| **桌宠大小** | 点一次在 80% → 100% → 120% 之间循环 |
| 切换置顶 | 是否压在其他窗口上 |
| 开机自启 | 切换自启 |
| 打开完整设置 | 跳到聊天窗的设置面板 |
| 打开 Hermes 目录 | 打开本机 Hermes 数据目录 |
| 安静一会儿 | 临时隐藏桌宠 |
| 退出 | 关闭桌宠 |

### 点状态胶囊
桌宠头上那个「在线 · N 个在跑」的小胶囊，点开是 Hermes 的状态面板：执行中 / 待验收 / 受阻 / 排队，以及当前任务和执行端。

### 拖文件给它
把文件拖到角色身上，会弹出「派一个活给 Hermes」的面板，文件作为附件随任务上传。

## 三、它和 Hermes 是怎么连的

两条方向，都不用你操心：

**Hermes → 桌宠（自动）**：Hermes 有任务在跑时，桌宠自动走「待命 → 执行中 → 思考 → 成功 / 失败」，跑完弹气泡 + 系统通知。你什么都不用做。

**桌宠 → Hermes（主动）**：拖文件、或在聊天窗里说话，等于把任务派给 Hermes。

底层是一条 `127.0.0.1` 的本机桥：桌宠启动时在 `%LOCALAPPDATA%\hermes\hermes-pet-bridge.json` 写端口和 token，Hermes 插件读它来调用；桌宠每 3 秒轮询 Hermes 的状态与看板。

## 四、聊天窗

打开方式：右键 → 打开对话，或按 `Ctrl + Shift + H`。

顶部按钮：

| 按钮 | 作用 |
|---|---|
| 任务 | 手动创建任务 |
| 记忆 | 看 Hermes 记得的东西 |
| 技能 | 看已装的技能 |
| 听 | 语音输入 |
| 读 | 朗读 / 停止朗读 |
| 设置 | 打开设置面板 |

## 五、设置面板（每一项说明）

### 称呼
- **主人称呼**：它叫你什么
- **桌宠名字**：它自称什么（也用作系统通知标题）

### 外观（拖动即时生效，不用先保存）
- **桌宠大小**：70% ~ 140%。窗口以右下角为锚点缩放，角色等比跟随
- **不透明度**：40% ~ 100%。只影响角色本体，气泡和菜单不受影响
- **主动台词**：
  - 安静 —— 不主动开口
  - 正常 —— 闲着时偶尔说一句
  - 话多 —— 更频繁

### 语音（系统离线语音，不花 API 费用）
- **语音播报**：总开关
- **音色**：自动挑选中文女声，也可以指定（本机有 Huihui / Kangkang / Yaoyao）
- **语速**：70% ~ 130%
- **音量**：0% ~ 100%
- **试听一句**：用当前设置念一句话，不保存也能听效果

> 播报前会自动去掉 markdown 符号和链接，长内容截断到 90 字。找不到中文语音包时静默降级，不会报错。

### 免打扰
- **启用免打扰时段**：时段内只是**静音**，桌宠照常在场、气泡照常显示
- **开始 / 结束**：支持跨午夜，例如 23:30 → 08:00
- **审批 / 需协助提醒仍出声**：这类提醒可以例外放行

### 连接与人设（默认折叠）
- API 地址、模型、API Key、专属人设
- 密钥只由主进程加密保存，聊天窗只拿到「是否已配置」
- **从 Hermes 导入密钥**：直接读 Hermes `.env` 里的 `DEEPSEEK_API_KEY` 与地址，
  加密后写入桌宠设置。首次启动如果还没配密钥，会自动导入一次

底部：**恢复默认**（只复位外观 / 语音 / 免打扰，不动 API 与人设）、**保存设置**。

## 七、常见问题

**拖不见了怎么办？**
右键菜单已经用不到（窗口在屏外）。此时按 `Ctrl + Shift + H` 打开聊天窗，或从托盘图标右键 → 回到右下角。

**没有声音？**
设置面板 → 语音 → 点「试听一句」。如果提示没找到中文语音包，说明系统没装中文语音（Windows 设置 → 时间和语言 → 语音 里可以添加）。

**角色边缘有过淡的残影？**
歪头时头部轮廓外侧有一圈极淡的柔边，这是旋转时用来填缝的过渡像素，在正常显示尺寸下不可见。

**它会不会一直弹提示？**
不会。只有任务状态真实变化时才播报，且同一件事不会重复说。

## 八、当前能力边界

- 语音是**系统离线合成**，不是预录的高质量配音，音色偏机械
- 表情只有「睁眼 / 半闭 / 闭眼 / 张嘴」几种，还没有害羞、生气这类独立表情
- 没有余额 / 消耗看板（Hermes 不按量计费，用不上）
