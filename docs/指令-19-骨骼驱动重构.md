# 指令 19 · 把已有的能力用起来：从「CSS 形变」到「骨骼驱动」

> 这份是重新设计，不是补丁。查了一圈之后我发现一件事：**项目里最有能力的渲染器一直在跑，但它只被用了 4 个参数，而精心做的 15 个动作在它面前全部作废。**
> 所以「更聪明、更像人的动作」不需要新素材、不需要新引擎——需要把已有的东西接起来。

---

## 一、先说真实现状

### 1.1 渲染器其实是骨骼级的

`renderer/pet-puppet.js`（495 行）是一个自研的 2.5D 分层渲染器，PixiJS 驱动，五层：

```text
assets/pet-layers/
├─ body.png    460KB   身体（含披风、裙子）
├─ head.png    467KB   头部（眼窝替换成闭眼眼皮）
├─ eyes.png     28KB   眼睛（睁眼/闭眼差分）
├─ mouth.png     3KB   嘴（闭合/张开差分）
└─ shadow.png   21KB   脚底投影
```

`meta.json` 里定义了切缝和轴心：

```json
{ "canvas": { "width": 448, "height": 841 },
  "head": { "cutY": 258, "pivotX": 224, "pivotY": 258 },
  "eyes": { "x": 145, "y": 152, "w": 159, "h": 64 },
  "mouth": { "x": 202, "y": 216, "w": 47, "h": 32 } }
```

**它支持的骨骼参数有 6 个**（`pet-puppet.js:15-20`）：

| 参数 | 含义 | 空闲值 | success | error | sleep |
|---|---|---|---|---|---|
| `rot` | 头部倾角 | 0 | 0 | -1 | -4 |
| `dy` | 头部纵向位移 | 0 | -10 | +9 | +10 |
| `eye` | 眼睛开合 | 1 | 0.3 | 0.52 | 0 |
| `mouth` | 嘴开合 | 0 | 0.55 | 0.15 | 0 |
| `breath` | 呼吸强度 | 1 | 1.1 | 0.8 | 0.65 |
| `lean` | 身体侧倾 | 0 | 0 | -1.5 | -2 |

外加 `jump`（整体纵向冲击）和一套粒子系统（heart / star / note / dust / sweat）。

**日志确认它一直在正常工作**：

```text
[pet-puppet] 图层就绪 448x841 切缝 y=258
```

### 1.2 但 15 个动作在它面前是死的

`renderer/style.css:175`：

```css
body[data-live2d="on"] #pet-gesture { animation: none; }
```

puppet 启用时（默认启用），**所有 CSS 手势动画被整体关掉**。

也就是说：`hat-check`、`jelly-bounce`、`quick-hop`、`sparkle-cast` 这 15 个动作、31 段 `@keyframes`、上一轮花力气修的 `animation-duration` 和欠帧问题——**在用户实际看到的那个版本里，一个都不播**。

### 1.3 点击的实际反应是 4 个硬编码

`pet-puppet.js:456-478`：

```js
onInteract(zone) {
  if (zone === 'head')  { imp.rot = -10; imp.dy = -4; /* 爱心粒子 */ }
  else if (zone === 'face')  { 眨眼一次; /* 星星粒子 */ }
  else if (zone === 'body')  { imp.lean = 5; imp.rot = 3; /* 音符 */ }
  else if (zone === 'feet')  { imp.jump = -14; /* 尘土 */ }
  setTimeout(() => { imp.rot = 0; imp.dy = 0; imp.lean = 0; }, 700);
}
```

**四个热区，每个只有 1~2 个自由度、固定幅度、700ms 后归零。**

有一个能独立旋转头、独立开合眼睛和嘴、独立弯曲身体的骨骼系统，实际用出来的是「整张图歪 10 度」。

**这就是「动作不够像生物」的真正原因。不是动作不够多，是它们没接到骨骼上。**

## 二、正确的模型：动作 = 骨骼参数的时序曲线

### 2.1 从 CSS transform 改成 track

现在的动作是 CSS：

```css
@keyframes quickHop {
  0%   { transform: translateY(0) scale(1); }
  24%  { transform: translateY(-14px) scale(.96, 1.06); }
  54%  { transform: translateY(2px) scale(1.05, .93); }
  100% { transform: translateY(0) scale(1); }
}
```

它只能动**整张合成的图**。头不会转、眼不会动、嘴不会开。

改成骨骼曲线（`pet-actions.js` 里加 `tracks`）：

```js
{
  id: 'quick-hop', group: 'feet', effect: 'dust', duration: 720,
  tracks: {
    // [归一化时间 0~1, 值]，中间线性插值
    jump:  [[0, 0], [0.24, -14], [0.54, 2], [0.74, -2], [1, 0]],
    lean:  [[0, 0], [0.24, -2], [0.54, 3], [1, 0]],
    eye:   [[0, 1], [0.30, 1.25], [0.62, 0.85], [1, 1]],
    mouth: [[0, 0], [0.48, 0.30], [1, 0]],
    rot:   [[0, 0], [0.24, -3], [0.54, 2], [1, 0]]
  }
}
```

同样的 720ms、同样的尘土粒子，但**头会转、眼会睁大又收小、嘴会张一下、身体会弯**。

### 2.2 五层的自由度是「叠加」的，不是「切换」的

这是骨骼模型比 CSS 强的地方：多个动作、常驻状态、表情，可以同时作用在不同自由度上。

```text
最终姿态 = 常驻层（呼吸） + 动作层（当前动作的 tracks） + 情绪层（情绪偏置） + 冲击层（物理冲量）
```

| 层 | 作用 | 例子 |
|---|---|---|
| 常驻层 | 永远在跑 | `breath` 正弦、`rot` 微漂移 |
| 动作层 | 当前动作的 tracks | 点击触发的跳跃曲线 |
| 情绪层 | 情绪对参数的整体偏置 | 犯困时 `eye -= 0.3`、`rot -= 2`；兴奋时 `eye += 0.15`、`breath *= 1.3` |
| 冲击层 | 瞬时物理响应 | 被戳时的 `imp.rot = -10`，指数衰减回 0 |

**四层相加，而不是互相覆盖。** 这就是「一个动作」和「一次全身反应」的区别。

### 2.3 什么样的动作才像人：多关节协同

人类动作的特点是**多个关节同时、但不同步**。举三个现在做不出来的例子：

**「被戳脸」**
```js
tracks: {
  rot:   [[0, 0], [0.18, -7], [0.5, 4], [0.8, -1], [1, 0]],   // 头先躲
  dy:    [[0, 0], [0.18, -3], [0.6, 1], [1, 0]],
  eye:   [[0, 1], [0.08, 0.15], [0.34, 0.15], [0.5, 1.1], [0.7, 0.95], [1, 1]],  // 先闭眼，再睁大
  mouth: [[0, 0], [0.3, 0.25], [0.6, 0], [1, 0]],
  lean:  [[0, 0], [0.3, -2], [1, 0]]                          // 身体比头晚动
}
```
头 18% 才到峰值，身体 30% 才动——**有先后**。眼睛先闭（挨了一下）再睁大（看清是谁）。

**「歪头看」**
```js
tracks: {
  rot:   [[0, 0], [0.3, 12], [0.75, 12], [1, 0]],   // 歪住不动一会儿
  eye:   [[0, 1], [0.2, 1], [1, 1]],
  lean:  [[0, 0], [0.35, -1.5], [0.8, -1.5], [1, 0]] // 身体反向一点点，重心平衡
}
```
`rot` 有 45% 的时间停在同一个值——**人是会保持一个姿势的**，CSS 关键帧很难做出这种「停住」。

**「被你气到」**
```js
tracks: {
  rot:   [[0, 0], [0.25, -14], [0.6, -14], [0.9, -10], [1, 0]],  // 扭头背过去
  eye:   [[0, 1], [0.2, 0.6], [0.7, 0.6], [0.85, 1], [1, 1]],     // 眯着眼，最后忍不住睁开
  mouth: [[0, 0], [0.2, 0], [0.85, 0.2], [1, 0]],
  lean:  [[0, 0], [0.3, 4], [0.7, 4], [1, 0]]
}
```
0.85 处眼睛睁开那一下，就是「忍不住看一眼」——**一个动作里藏了一段心理活动**。

以上三个都能用现有素材做出来，因为骨骼参数是独立的。

## 三、表情也该跟着改

### 3.1 现在：12 张硬切

`renderer/pet.js:27-38` 的 `paintFace`，切换时 `opacity` 淡出 160ms → 换 src → 淡入。**是换图，不是表情变化。**

### 3.2 改成：骨骼表情 + 贴片混合

真人表情有两种：(1) 五官位置变化（骨骼能表达）(2) 皮肤细节（脸红、眼泪，贴片才能表达）。

**正确做法是两者叠加：**

```js
// 情绪 → 骨骼偏置 + 贴片
const EMOTION_POSE = {
  '开心': { eye: 1.12, mouth: 0.35, rot: 1,  face: 'happy' },
  '得意': { eye: 0.92, mouth: 0.25, rot: -4, face: 'smug' },
  '有点烦': { eye: 0.78, mouth: 0.05, rot: -6, face: 'frown' },
  '委屈': { eye: 0.88, mouth: 0.15, rot: 5,  face: 'shy' }
};
```

然后**贴片用 crossfade 而不是替换**：两层 `<img>` 叠着，切换时旧的淡出、新的淡入，同时骨骼参数在 200ms 内插值过去。这样表情是「过渡」出来的，不是「弹」出来的。

**这一条能直接消掉用户说的「分层断层感」的一半**——因为贴片不再是硬邦邦地出现。

## 四、再往上一层：真人感的四个细节

骨骼接好之后，还有四件让「有骨骼的木偶」变成「活的生物」的事。

### 4.1 视线要有 saccade（跳视）

真人看东西不是一个平滑的追随，是「快速跳到某个点 → 停留 200~600ms → 微漂移 → 再跳」。

现在 `setLook(x, y)` 是线性跟随鼠标，像摄像头。

```js
// 每 300~800ms 跳一次，中间微漂移
let gazeTarget = { x: 0, y: 0 };
let gazeAt = 0;
function tickGaze(now, mouseX, mouseY) {
  if (now - gazeAt > 300 + Math.random() * 500) {
    gazeAt = now;
    // 60% 看鼠标，40% 看别处（人不是一直盯着一个东西）
    if (Math.random() < 0.6) {
      gazeTarget = { x: clamp((mouseX - 0.5) * 2, -1, 1), y: clamp((mouseY - 0.5) * 2, -1, 1) };
    } else {
      gazeTarget = { x: (Math.random() - 0.5) * 1.4, y: (Math.random() - 0.5) * 0.8 };
    }
  }
  // 跳过去要快（80~140ms），不是线性追
  lookX += (gazeTarget.x - lookX) * 0.35;
  lookY += (gazeTarget.y - lookY) * 0.35;
}
```

**加点漂移**：`lookX += Math.sin(now / 1100) * 0.004`——眼球永远有微颤。

### 4.2 习惯化：同一个刺激，反应会越来越弱

真人对第 1 次戳和第 10 次戳的反应完全不同。现在每次都是同样力度。

```js
// 每个热区独立记录「最近被碰的次数」，30 秒衰减一次
const pokes = { head: 0, face: 0, body: 0, feet: 0 };
const pokeAt = { head: 0, face: 0, body: 0, feet: 0 };

function pokeFactor(zone, now) {
  // 30 秒没碰就忘掉一半
  if (now - pokeAt[zone] > 30000) pokes[zone] = Math.floor(pokes[zone] * 0.3);
  pokeAt[zone] = now;
  pokes[zone] += 1;
  return Math.max(0.25, 1 / (1 + pokes[zone] * 0.35));   // 第1次1.0，第3次0.49，第6次0.32
}
```

幅度乘 `pokeFactor`。**第 6 次戳它只轻轻动一下，第 7 次干脆不动**——这个「懒得理你」比任何台词都像活的。

### 4.3 微动作噪声：永远不完全静止

现在呼吸是一个 3.6 秒的完美正弦。完美 = 死。

```js
// 三组不同周期叠起来，永不重复
const n1 = Math.sin(now / 3600) * 0.012;
const n2 = Math.sin(now / 1770 + 1.3) * 0.007;
const n3 = Math.sin(now / 940 + 2.7) * 0.004;
const breathNoise = n1 + n2 + n3;
```

再叠一个**偶发的微抽搐**（平均 20~40 秒一次，很轻）：

```js
// 生物会有不自主的小抽动
if (now - lastTwitch > 20000 + Math.random() * 20000) {
  lastTwitch = now;
  imp.lean += (Math.random() - 0.5) * 1.2;
}
```

### 4.4 无意识的自我调整

人没事干的时候会摸头发、拉衣服、调整帽子。这类动作叫「自我接触」，是「无聊但在」的强信号。

用现有素材能做：`hat-check`（摸帽子）、`cape-flick`（甩披风）、`side-brace`（撑一下腰）——**这些动作现在被当通用动作随机播，改成「只在长时间没事干时出现」**，含义就完全不同了。

```js
// 只有 idle 超过 4 分钟，才可能出现自我调整类动作
const GROOMING = ['hat-check', 'cape-flick', 'side-brace'];
if (behavior === 'idle' && idleMs > 240000 && Math.random() < 0.3) {
  playAction(GROOMING[Math.floor(Math.random() * GROOMING.length)]);
}
```

## 五、落地顺序（五步，每步独立可验）

### 第 1 步：接通骨骼（最大收益）

1. `pet-actions.js` 给 15 个动作加 `tracks`
2. `pet-puppet.js` 暴露 `playTrack(tracks, duration)` 接口
3. `renderer/pet.js` 的 `playAction` 改成：puppet 在跑就调 `playTrack`，否则回退 CSS
4. **删掉 `body[data-live2d="on"] #pet-gesture { animation: none; }` 这条规则**——它就是为了防止两套动画打架，接通之后不需要了

验收：点脚，头的倾角、身体前倾、眼睛开合**同时**在变，而且不同步；`quick-hop` 时影子跟着缩小变淡。

### 第 2 步：四层叠加

常驻（呼吸）+ 动作（tracks）+ 情绪（偏置）+ 冲击（瞬时）。

验收：把情绪设成「犯困」，再做 `quick-hop`——动作幅度要打折（因为情绪层给 `eye` 和 `breath` 加了负偏置），跳起来也是没劲的。

### 第 3 步：表情从换图改成混合

两层 `<img>` crossfade + 骨骼偏置插值。

验收：从「开心」切到「有点烦」的过程中截图，中间帧应该是两种表情的叠加态，不是干净的一帧。

### 第 4 步：saccade + 微噪声 + 抽搐

验收：录 10 秒视频，视线不能是平滑追踪鼠标的轨迹，要有跳和停。

### 第 5 步：习惯化 + 自我调整

验收：连续点身体 6 次，第 5、6 次的幅度明显小于第 1 次；静置 5 分钟，能看到它自己摸帽子。

## 六、不许做的

1. **不要把 `tracks` 写成 CSS 关键帧的翻译**。CSS 的 `translateY` 只能动整体，骨骼能分别动头和身体——照着 CSS 翻就浪费了这个能力
2. **四层叠加不能改成择一**。叠加是骨骼模型的核心价值
3. **不要删 `pet-puppet.js` 的 CSS 回退路径**。PixiJS 加载失败时要能退回静态立绘（`pet-puppet.js:339` 那段 `catch` 保留）
4. **习惯化的下限不要低于 0.25**。完全不动会让人以为坏了
5. **第 1 步做完之前，别动表情和习惯化**。骨骼没接通，那些都是空中楼阁

## 七、验收的最终判据

做完第 1 步之后，录一段 10 秒视频，逐帧看：

1. **头的旋转和身体的倾斜，是不是不同的角度、不同步的时间点？**
2. **眼睛的变化，是不是和头的转动发生在不同时间？**
3. **动作结束，是不是有一条平滑的回归曲线，而不是「啪」一下复位？**

三条都「是」，才叫骨骼驱动。任何一条是「整张图一起动」，说明还是 CSS 那套。

汇报时贴视频路径和逐帧截图，不要写「动作更自然了」。
