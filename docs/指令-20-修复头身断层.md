# 指令 20 · 修掉头身断层（拆层脚本）

> 上一轮我判断错了。我说「`body.png` 的头部区域被挖空，所以要改成保留完整原图」——**挖空是刻意的，改回去会出双头虚影。**
> 真正的病因是另一处：`head.png` 在切缝处硬切，一旋转就露出底下。这是标准骨骼动画里该用「过画（over-paint）」解决的事，但这个脚本没做。

---

## 一、诊断数据

```text
body.png  448x841
  切缝以上 y<258    不透明像素 0 / 114688 = 0.0%
head.png  448x841
  切缝以上 y<258    不透明像素 66660 / 114688 = 58.1%

沿切缝逐行看：
  y=248   body 不透明 0     head 277
  y=258   body 187          head 251     ← 只有这一行有重叠
  y=268   body 201          head 0       ← head 在这里完全消失
```

`head.png` 在 y=258 以下是**零个像素**。头部绕 (224, 258) 旋转 8 度时，头发顶部（距轴心约 250px）横移 `250 × sin(8°) ≈ 35px`。切口硬切在 258，下面又没有任何兜底像素，**旋转时那条缝就是透明的**——露出来的是桌面壁纸。

这就是用户说的「分层断层、间煥感」的主因。

## 二、为什么不能简单「body 保留完整原图」

`tools/build-pet-layers.js:101-103` 的注释已经写了原因：

```js
/* body 层：挖掉整个头部区域。
   之前 body 保留完整原图，歪头时底下的原头部会露出来，两套轮廓叠成虚影。
   挖掉后头只由 head 层提供，转动时不会再出现第二张脸。 */
```

这是走过一遍的坑，别再踩回去。

另外脚本里有个**死常量**：

```js
const BODY_PAD_TOP = 232;   // 身体层向上补绘的高度（头部转动时填缝）
```

`grep BODY_PAD_TOP` 全项目只有这一行定义，**从来没被用过**。注释写的是对的思路，代码没实现。

## 三、修法：两边一起过画

标准做法是「让两个图层在切缝附近互相覆盖」——head 向下多留一截，body 向上多留一截，中间形成一段双层缓冲带。旋转时不管往哪边偏，都有像素顶着。

### 改动 1：`head.png` 向下过画 32px

`tools/build-pet-layers.js:89` 现在是这样：

```js
const headMask = U.floodMask(O, PIVOT.x, Math.round(NECK_CUT_Y * 0.72), NECK_CUT_Y);
```

`floodMask` 的第 4 个参数是 `maxY`，卡死在 258。**不能直接把 maxY 调大**——`floodMask` 是四连通填充，头、脖子、身体在像素上是连着的，调大之后 head 会把整个身体吃进去。

正确做法：先按原样得到 `headMask`，再手工补一条过画带：

```js
const NECK_CUT_Y = 258;
const HEAD_OVERPAINT = 32;      // 头部向下过画的高度

const headMask = U.floodMask(O, PIVOT.x, Math.round(NECK_CUT_Y * 0.72), NECK_CUT_Y);

/* 头部向下过画：head 层原来在 cutY 处硬切，旋转 8 度时切口会横移 30px 以上，
   下面没有像素兜底就露出透明。这里把 cutY 以下的原图内容多留一截，
   alpha 从 1 线性淡到 0，形成一段「裙边」，旋转时盖住切口。 */
for (let y = NECK_CUT_Y; y < Math.min(H, NECK_CUT_Y + HEAD_OVERPAINT); y++) {
  const fade = 1 - (y - NECK_CUT_Y) / HEAD_OVERPAINT;   // 1 → 0
  for (let x = 0; x < W; x++) {
    const i = y * W + x;
    if (O.data[i * 4 + 3] <= 8) continue;               // 原图这格是透明的，跳过
    headMask[i] = 1;
    // 记下这一格要用的 alpha 系数，后面 applyMask 时乘上去
    overpaintAlpha[i] = fade;
  }
}
```

`U.applyMask` 现在只做「保留/丢弃」二值处理。需要给它加一个可选参数，或者在这段之后单独走一遍 alpha 相乘：

```js
// applyMask 之后
for (const [i, fade] of Object.entries(overpaintAlpha)) {
  head.data[i * 4 + 3] = Math.round(head.data[i * 4 + 3] * fade);
}
```

### 改动 2：`body.png` 向上补绘到 232（把死常量用起来）

```js
const BODY_PAD_TOP = 232;   // 这个常量已经定义，一直没用

/* body 层：挖掉头部区域 + 从 BODY_PAD_TOP 到 cutY 之间保留原图内容。
   上面多留的 26px 是脖子和下巴，不是整张脸，所以不会出现双头虚影，
   但能在头部小角度旋转时兜住切口。 */
const bodyMask = new Uint8Array(W * H);
for (let p = 0; p < W * H; p++) {
  const y = Math.floor(p / W);
  if (!headMask[p]) bodyMask[p] = 1;
  else if (y >= BODY_PAD_TOP) bodyMask[p] = 1;   // 切缝附近的头部像素也留在 body 上
}
U.applyMask(body, bodyMask);
```

**注意这里有个取舍**：`headMask` 里 232~258 之间的像素会同时出现在 head 和 body 两层。叠在一起时是同一个像素画两次，看不出来；头转开时 body 那份留在原地兜底。这是刻意做的双层。

### 改动 3：`HEAD_EDGE` 从 9 降到 4

```js
const HEAD_EDGE = 9;   // 原来
const HEAD_EDGE = 4;   // 改成 4
```

`expandEdge(head, headMask, 9)` 是沿轮廓向外扩 9px、alpha 逐层衰减。9px 的毛边在头部静止时会让轮廓显得发糊——**用户说的「间煥感」有一部分就是这圈毛边**。有了向下过画之后，缝不靠毛边填了，毛边可以收窄到 4px 只做抗锯齿。


## 五、不许做的

1. **不要把 body 改回「保留完整原图」**。会出双头虚影，这在 `build-pet-layers.js:101-103` 的注释里写着，是踩过的坑
2. **不要直接把 `floodMask` 的 maxY 调大**。四连通填充会把整个身体吃进 head 层
3. **不要在没备份的情况下覆盖 `assets/pet-layers/`**。这套图层是逐像素对齐出来的，重做成本高
4. **改完不要顺手调 `PIVOT` 和 `NECK_CUT_Y`**。轴心位置是测量出来的，动了要重新对齐整套
