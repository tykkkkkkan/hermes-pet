|---|---|---|---|---|---|

| A2 | **idle 闭眼** | 1 | **P0** | 与 A1-idle 完全相同，只闭眼 | 眨眼（每 3–6 秒一次） |
| A3 | **走路两帧** | 2 | P1 | 迈步 / 并拢 | 走路循环 |
| A4 | **挥手** | 1 | P1 | 举手挥动，笑 | 打招呼、提醒你看 |

### A 类硬规格

| 项 | 要求 |
|---|---|
| 画布 | 1024² 起，正方形，越大越好（1536/2048） |
| 格式 | PNG 透明，**真 alpha**（拖到深色背景看，不能有白边） |
| 脚底 | 距画布底部 5%，所有图同一条线 |
| 中轴 | 身体正中，所有图同一条线 |
| 头顶 | 不高于距顶部 5%（举手跳跃姿势要留余量） |
| 视角 | 一律正面 |
| 光照 | 主光左上，阴影落右下 |
| 禁止 | 投影、地面、背景、描边、发光、文字、拼图 |

# B · 表情头像（聊天窗 / 气泡左侧小头像）

**尺寸小、使用频率最高**。聊天时每句话旁边都有它。

| 编号 | 名称 | 张数 | 优先级 | 说明 |
|---|---|---|---|---|
| B1 | 平常 / 开心 / 困 / 思考 / 不满 / 委屈 | 6 | **P0** | ✅**已有**（512² 头部特写，共用裁切框） |
| B2 | 得意 | 1 | P1 | 挑眉、嘴角上翘、眼神斜视 |
| B3 | 无语 | 1 | P1 | 半月眼、嘴角平、额角一滴汗 |
| B4 | 震惊 | 1 | P1 | 瞳孔缩小、嘴巴 O 形、身体后仰 |
| B5 | 害羞 | 1 | P2 | 脸泛红、视线游移、手挡嘴 |

### B 类规格

- **512 × 512**，头部特写（到肩膀）
- **共用同一个裁切框**——六张必须头的位置、大小完全一致，切换时不跳
- 透明底，不带头发以外的任何元素
- 提示词里要写明「头部特写，肩膀以上，头部居中占画面 80%」

# E · 特效与情绪符号

大肥鱼的那些"冒汗、星星、爱心"不是画在立绘里的，是**独立图层叠上去的**。这样同一个动作能配不同情绪。

| 编号 | 名称 | 数量 | 优先级 | 说明 |
|---|---|---|---|---|
| E1 | 情绪符号 7 个 | 7 | P1 | 汗滴 / 爱心 / 星星 / 感叹号 / 问号 / 音符 / 省略号 |
| E2 | 光环脉冲 | 1 | P1 | 背后扩散的光圈，用于完成/高亮 ✅**部分已有（fx/halo）** |
| E3 | 羽毛飘落 | 1 套 4 帧 | P2 | 4 帧循环下落 |
| E4 | 星尘粒子 | 1 张 | P2 | 小光点，程序随机撒 |

### E1 规格

- **256 × 256**，透明底
- 单个符号，**居中，占画面 70%**
- 简单平涂 + 一点高光即可，不要渐变复杂
- 与立绘同一画风（同色系、同描边粗细）

# 通用铁律（七类全部适用）

| ❌ 绝对不要 |
|---|
| **拼图**——多张挤一张图里（之前 6 张表情是 3×2 拼的，拆格会把分隔线判进角色） |
| **假透明**——白底或绿底然后用"看起来像透明"，必须是真 alpha |
| **画死影子**——影子由程序按壁纸动态生成 |
| **描边 / 外发光 / 锐化 / 降噪**——会破坏 alpha 边缘，抠图出毛刺 |
| **文字标签**——除非是 C 类明确要求带标题的插画 |
| **缩到刚好**——四周永远留余量，特别是顶部 |

| ✅ 一定要 |
|---|
| 同一套角色特征：发色、发型、瞳色、服装层数、配饰、翅膀张角，**每张逐字一致** |
| 同一光照方向：主光左上，阴影右下 |
| 原始大图给我，**不要自己压缩** |
| 文件名用英文状态名，不用「图1」「最终版」 |
