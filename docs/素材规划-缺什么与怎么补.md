## 二、那七张为什么是关键

你现在有两个东西缺一个连接：

- **`renderer/behavior.js` 有 9 种行为状态**（sleeping / drowsy / idle / curious / focused / worried / pleased / sulky / clingy）
- **七张姿态图正好覆盖这些状态的视觉表达**

| 行为状态 | 该用哪张图 | 现在的表现 |
|---|---|---|
| `sulky`（闹脾气） | `pose-back`（背对你） | 只有骨骼偏转，看不出在赌气 |
| `curious`（好奇） | `pose-side`（侧身偷看） | 只有视线偏移 |
| `clingy`（黏人） | `pose-wave`（挥手） | 没有 |
| `focused`（专注） | `pose-point` 或 `pose-trust` | 没有 |
| `worried`（不安） | `state-annoyed` | 用 `state-error` 凑 |
| 走动 | `walk-contact` | 角色永远钉在屏幕一角 |

**「背对你」这个姿态，比任何骨骼参数都更能表达「我在生气」。** 一张图的效果超过三十行曲线。

这七张是零成本的，接上代码当天就能看到差别。

## 三、真正缺的素材（按「像生物」排）

### 缺口 1：手臂（影响最大）

现在 `body.png` 是一整块，含手臂但动不了。人类动作大半靠手——摊手、抱胸、撑腰、指、托腮，一个都做不出来。

**需要**：左臂、右臂各一张独立层（含手），以及「手臂贴身」（默认）和「手臂张开」（动作时）两个状态。

### 缺口 2：头发和披风（第二重要）

角色的银发和披风现在烤死在 head/body 里，跟着整体动。真实感的「二次运动」（secondary motion）全靠这个——头动了，头发晚 80ms 才跟上。

**需要**：
- 后发（在身体后面，可独立摆动）
- 前发（盖在脸上、肩上，可轻微飘）
- 披风（可独立摆动）

### 缺口 3：眉毛（表情的一半）

现在只有 `eyes.png` 和 `mouth.png` 两张开合图。**表情的 60% 靠眉毛**，没有眉毛就只能「睁眼/闭眼」，做不出「皱眉」「挑眉」「无奈」。

**需要**：眉毛层，4~6 种状态（平、上扬、下垂、皱眉、外八）。

### 缺口 4：嘴型（说话像机器人）

现在 `mouth.png` 只有开合两态。说话就是嘴一张一合，明显是机械的。

**需要**：5 种口型（闭合 / a / i / u / e·o），或者至少 3 种。

### 缺口 5：走路缺帧

`walk-contact.png`（迈步）有，`walk-pass.png`（并拢）**缺**。走路循环至少要两帧才能动起来。

### 缺口 6：侧面只有一张

`pose-side.png` 是固定角度。要做「转头看你」的连续过程，需要至少 3 个角度（正 / 3/4 / 侧）。现在的做法是骨骼旋转，超过 15 度就会露馅（这也是上一份指令要修断层的原因）。

## 四、分四档，按性价比排

### A 档 · 零成本（手上就有）

| 素材 | 用途 | 谁做 |
|---|---|---|
| `pose-back` | `sulky` 状态 → 背对你 | Codex |
| `pose-side` | `curious` 状态 → 侧身偷看 | Codex |
| `pose-wave` | 打招呼 / `clingy` | Codex |
| `pose-point` | 指向任务 / `focused` | Codex |
| `pose-trust` | 托腮发呆 / `drowsy` | Codex |
| `state-annoyed` | `worried` 状态 | Codex |
| `walk-contact` | 走动（等 B 档补齐另一帧） | Codex |

**做法**：`preload.js` 的 `stateSources` 加映射，`behavior.js` 的行为状态直接选姿态图。骨骼层（puppet）负责脸和微动，姿态图负责整体剪影。

**这里有个技术选择要定**：puppet 用的是 `pet-layers/`（五层），七张姿态图是**整图**。两套怎么共存？

两种方案：
1. **切换整套**：进 `sulky` 时隐藏 puppet，显示 `pose-back` 整图。简单，但失去骨骼微动
2. **只换 body 层**：给每张姿态图拆出 body/head，成本高

**建议先做方案 1**——姿态图是「大动作」，骨骼是「微动作」，两者不需要同时。切换时用 200ms 交叉淡化。

### B 档 · AI 生图能补（1~2 小时）

沿用 `docs/豆包生图指令-全集.md` 那套流程（参考图只用站姿那一张、一条指令一张图、1:1、原样保存不抠底）。

| 素材 | 数量 | prompt 要点 |
|---|---|---|
| `walk-pass.png` | 1 | 「同角色，走路循环另一帧：双脚并拢」「站姿立绘同机位、同光照、同画幅」 |
| 眉毛层 | 5 | 「同角色，只改眉毛：平直 / 上扬 / 下垂 / 皱起 / 内八」「其余像素完全不变」 |
| 嘴型 | 5 | 「同角色，只改嘴巴：闭合 / 张嘴 a / 扁平 i / 圆 u / 微笑 e」「其余不变」 |
| 腮红 | 1 | 「同角色脸颊加半透明粉色红晕，alpha 30%」 |
| 眼泪 | 1 | 「眼角一颗泪珠」 |

**难点在一致性**，靠现有流程能控住：项目的 `tools/build-pet-layers.js` 已经在做「睁眼 - 闭眼 = 眼睛层」的差分，同样的方法能吃眉毛和嘴型。**前提是新图和 `state-idle.png` 逐像素对齐**——这就是为什么参考图只能用那一张站姿，不能拿上一张的输出当输入。

### C 档 · AI 生图 + 程序配合（半天到一天）

| 素材 | 做法 | 风险 |
|---|---|---|
| 手臂（左/右） | 生「手臂抬起」和「手臂放下」两张同姿势图，用 `build-pet-layers.js` 的差分思路抠出差异像素当手臂层 | AI 很难保持除手臂外完全一致，差分出来会有噪点，需要人工挑 |
| 前发 / 后发 | 同上，生「头发被风吹起」和「头发静止」两张 | 头发是大面积，差分噪声更多 |
| 披风 | 同上 | 同上 |

这一档比 B 档难一个量级，因为**面积越大，AI 越难保持一致**。眉毛和嘴型是小区域，差分干净；手臂和头发是大区域，差分出来要人工修。

### D 档 · 不建议

| 方案 | 为什么不做 |
|---|---|
| 完整 Live2D 分层 PSD（几十层、边缘过画） | 美术工程量几十小时，AI 出不来严格对齐的多图层 |
| 真 3D 模型（GLB/VRM） | AI 图生 3D 对二次元角色容易形变，手工建模几十小时 |
| 全身体位（坐/蹲/躺） | 每增加一个姿势都要重拆整套骨骼层，收益递减 |

## 五、建议顺序

1. **A 档先接**（当天见效）。七张图接进 `stateSources` + `behavior.js`，`sulky` 时背对你、`curious` 时侧身偷看——这一条的效果比生成任何新素材都大
2. **B 档补齐**（一小时生图 + 一小时接）。`walk-pass` 先做，走路循环完整了，角色能「走」了；然后眉毛和嘴型，表情和说话立刻活
3. **C 档看心情**。手臂做到之后，「摊手」「抱胸」这类动作能出来，是质的提升，但成本高
4. **D 档别碰**

## 六、给你的判断依据

如果只能做一件事：**接 A 档那七张图**。

理由是一条：`behavior.js` 已经有 9 种状态了，但**状态的视觉表现全靠骨骼旋转几度**。用户看不出「它在生气」和「它在发呆」的区别，除非读台词。

七张姿态图接上之后，`sulky` 是背对你、`curious` 是侧身偷看、`clingy` 是挥手——**不用一个字就能看懂它在想什么**。这才是「智慧感」的视觉载体。

如果还能做第二件：**补 `walk-pass.png`**。一张图，让角色能从屏幕一角走到另一角，「生物」和「桌面挂件」的区别一下就出来了。

第三件：**眉毛**。五官里最容易做出表情的部分，5 张差分图，1 小时。
