## 三、下一项：情绪表情接入（现在效果最好的一件事）

你问过"效果最好的是什么"，答案就是这个，不是继续加动作。三条硬理由：

### 理由一：素材 100% 现成，一张都不用画

```text
assets/states/v2/aligned/face/
  face-angry.png      face-calm.png      face-cry.png        face-frown.png
  face-laugh.png      face-serious.png   face-shock.png      face-shy.png
  face-smug.png       face-speechless.png face-surprised.png  face-yawn.png
```

12 张，全部 1024×1024、PNG `colorType=6`（RGBA 带透明通道），和 `state/state-idle.png` **同尺寸、同对齐基准**。也就是说它们本来就是按"叠在整图上"设计的贴片，直接盖上去就对齐。

### 理由二：管线已经建到 80%，断在最后一步

`preload.js:17-27` 已经把 6 个映射配好了：

```js

  idle: v2File('face', 'face-calm'),
  happy: v2File('face', 'face-laugh'),
  sleepy: v2File('face', 'face-yawn'),
  thinking: v2File('face', 'face-serious'),
  angry: v2File('face', 'face-angry'),
  cry: v2File('face', 'face-cry')

```

`preload.js:42` 也通过 `contextBridge` 暴露出去了：

```js
contextBridge.exposeInMainWorld('pet', { regions: ..., actions: ..., faceSources, ... });
```

`renderer/pet.js:237-240` 每一帧都在算：

```js
const face = ['idle', 'happy', 'sleepy', 'thinking', 'angry', 'cry'].includes(s.face)
  ? s.face : faceByState[s.status] || 'idle';
petEl.dataset.face = s.status === 'error' && (...) ? 'cry' : face;
```

**但是——全项目没有任何一处消费它。**

```text

./preload.js:23:const faceSources = Object.fromEntries(...)
./preload.js:42:  faceSources,
```

只有定义和暴露这两行。`grep 'data-face' renderer/style.css` 零条规则，`#pet-inner` 里只有 `pet-body` 和 `pet-blink` 两个 `<img>`。

计算值算了、传了、没人用——这是断线，不是未开发。接上去的量级是"加一个 `<img>` + 几行切 src"，不是新功能。

### 理由三：脸是视觉焦点，这是质变不是量变

现在 15 个动作解决的是"身子会动"，而这个功能解决的是"它在看着我"。人看一个角色，注意力绝大部分在脸上；身体晃得再花，脸一直是同一张，就会一直是"一个会晃的图"。表情会变，才像活的。

顺带它还和你已有的情绪系统接上了——`petEl.dataset.emotion` 现在有 8 种（平静 / 开心 / 得意 / 犯困 / 有点烦 / 闹别扭 / 兴奋 / 平静），而 `style.css:218-225` 只是靠 `filter` 调饱和度亮度来"假装"情绪。用真表情图替掉 `filter`，情绪才看得见。

## 四、情绪表情接入怎么做（分两步，别一次做完）

### 第一步：先接 6 态，跑通再说

**`renderer/index.html`**，`#pet-inner` 里 `pet-body` 之后、`pet-blink` 之前插一层：

```html
<div id="pet-inner">
  <img id="pet-body" class="pet-layer pet-body" src="..." alt="赫尔墨兹" draggable="false" />
  <img id="pet-face" class="pet-layer pet-face" src="../assets/states/v2/aligned/face/face-calm.png" alt="" draggable="false" />
  <img id="pet-blink" class="pet-layer pet-blink-layer" src="..." alt="" draggable="false" />
</div>
```

顺序必须是 **body → face → blink**。眨眼层是整图闭眼帧（`state-idle-blink.png`），靠 `opacity: 0 → 1` 切换（`style.css:164-172`）。放最上面，眨眼时才盖得住表情层；放下面的话，睁眼的表情会盖在闭眼帧上，眼睛变成"两层眼"。

**`renderer/style.css`**，加：

```css
/* 表情层：换图时先淡出再淡入，避免生硬跳变 */
.pet-face {
  opacity: 1;
  transition: opacity .16s ease-out;
}
.pet-face.swapping { opacity: 0; }
```

**`renderer/pet.js`**，取元素并写切换函数：

```js
const petFace = document.getElementById('pet-face');

let faceTimer = null;
function paintFace(key) {
  const src = window.pet.faceSources?.[key];
  if (!src || petFace.src.endsWith(src.replace('..', ''))) return;
  // 先淡出再换图，换完淡入；160ms 是配合 style.css 的 transition 时长
  petFace.classList.add('swapping');
  clearTimeout(faceTimer);
  faceTimer = setTimeout(() => {
    petFace.src = src;
    petFace.classList.remove('swapping');
  }, 160);
}
```

在 `paintState` 里 `petEl.dataset.face = ...` 那行**之后**调用：

```js
paintFace(petEl.dataset.face);
```

注意：`paintState` 是状态推送时调用的（不是每帧），所以不会每帧都触发 `setTimeout`。但保险起见 `petFace.src.endsWith(...)` 那个判断要留着，防止同一个 key 反复触发。

**这一层先别碰 `live2d` 模式**。`body[data-live2d="on"]` 下 `#pet-inner` 整个不显示，`pet-face` 跟着隐藏，不用额外处理。

### 第二步（第一步验完再做）：把闲置的 6 张接给情绪

`face-frown` / `face-shock` / `face-shy` / `face-smug` / `face-speechless` / `face-surprised` 现在全闲置。它们配 `petEl.dataset.emotion` 的 8 种情绪正好：

| emotion | face | 备注 |
|---|---|---|
| 平静 | `face-calm` | 已有 |
| 开心 | `face-laugh` | 已有 |
| 得意 | `face-smug` | 闲置 |
| 犯困 | `face-yawn` | 已有 |
| 有点烦 | `face-frown` | 闲置 |
| 闹别扭 | `face-speechless` | 闲置 |
| 兴奋 | `face-surprised` | 闲置 |
| （待定） | `face-shy` / `face-shock` | 留给触摸互动：摸头害羞、被戳惊吓 |

**优先级规则要写清**：状态表情（`status`/`failureSeverity`）高于情绪表情。Hermes 报错时必须是 `face-angry` 或 `face-cry`，不能被"此刻心情不错"的 `face-laugh` 盖掉。

另外 `style.css:218-225` 那几条 `#pet[data-emotion="..."] .pet-body { filter: ... }` 要跟着收：有了真表情图，`saturate(1.2) brightness(1.04)` 这种"假装情绪"的滤镜就该减淡或去掉，两套叠加会脏。**只留 drop-shadow，把色相/饱和度相关的滤镜删掉。**
