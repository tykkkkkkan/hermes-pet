# 指令 03 · 图像立体化接入

> 这份是给 Codex 的执行说明。图像本身已经处理完，**不需要重新生成或重绘**，这里只讲怎么把它接到 Electron 窗口里，以及为什么要这么接。

---

## 一、这次图像改了什么

| 文件 | 尺寸 | 处理 |
|---|---|---|
| `assets/states/body/idle.png` | 1024² | 去底清理 + 体积重打光 |
| `assets/states/face/expr_1..6.png` | 512² | 同源处理，参数收敛（表情图显示尺寸小，不能压太狠） |
| `assets/states/fx/shadow.png` | 1024² | 新增 · 压扁贴地落影 |
| `assets/states/fx/contact.png` | 1024² | 新增 · 脚底接触影 |
| `assets/states/fx/halo.png` | 1024² | 新增 · 背后泛光 |
| `assets/states/shots/*.png` | 720² | 轻量立体化（清晰度 0.45 / 边缘光 0.22 / 不沉降），保留原构图与手写标题 |

具体做了四件事：

1. **去底清理**：原图腿缝里塞着纯白不透明像素（8161 px，会在深色壁纸上露出一道白楔子），脚下一圈浅灰"白影子"（1906 px，深色壁纸上是白斑）。两者都清掉了。
2. **清晰度**：`v' = v + k·(v − blur(v))`，按梯度加权，**只拉柔和明暗过渡，不碰线稿硬边**，所以不会把轮廓拉出毛刺。
3. **凹陷遮蔽**：只压"明显低于周边"的窄区（发缝、褶皱、裙下），上限 26%，避免整体变灰。
4. **暗部边缘光**：**只作用于亮度 < 0.55 的部分**。这条很关键 —— 赫尔墨兹是银发白裙，亮部加光会把白发白翅膀烧成白团（第一版就踩了这个坑）。

附：饱和度做了 1.12 倍补偿，因为按亮度缩放 RGB 会顺带掉 8% 饱和。整体亮度变化 −0.76%，肉眼不可见。

**重新生成**：`node tools/build-pet-3d.js`
它从 `.bak-flat/` 读平涂原图，所以**可以反复跑，不会叠加**。改完图想快速看效果：`node tools/render-mock.js`。

## 二、先说调研结论：大肥鱼的"立体"不是 3D

读了 `YU-1021/deepseek-fish-pet` 的 `app/renderer/style.css`，事实是：

```css
#pet { width: 350px; height: auto; display: block; margin: 0 auto; }
```

- 就是**一张平面 PNG**，没有 3D 模型、没有视差、没有烘焙光影
- 立绘本身**没有** drop-shadow（只有气泡和 emoji 特效有）
- 它的"活起来"全靠 `transform` 形变：

```css
@keyframes bounce {
  0%   { transform: scale(1); }
  25%  { transform: scale(.9, .84) translateY(-6px); }
  50%  { transform: scale(1.08, 1.1) translateY(2px); }
  75%  { transform: scale(.97, 1.03); }
  100% { transform: scale(1); }
}
@keyframes actBlush { 35% { filter: saturate(1.45) brightness(1.06) hue-rotate(-6deg); } }
```

**挤压拉伸（squash & stretch）+ 高饱闪烁 + 透明无边框窗口**，这三样造成了"立体摆件"的错觉。

所以有两条路，可以都做，B 建立在 A 之上。

## 三、方案 A：与大肥鱼完全一致（先做这个）

改动最小，只碰 CSS，不动窗口结构。

```html
<img id="pet" src="assets/states/body/idle.png" draggable="false">
```

```css
#pet {
  width: 350px;
  height: auto;
  display: block;
  margin: 0 auto;
  pointer-events: auto;          /* 只有它可点，其余层全部 no */
  -webkit-user-drag: none;
  transform-origin: 50% 96%;     /* 锚点锁脚底，形变才不会飘 */
  filter: drop-shadow(0 3px 6px rgba(10, 16, 32, .22));
}
```

```css
/* 待机呼吸：幅度必须极小，超过 2% 就像在抽搐 */
@keyframes idleBreathe {
  0%, 100% { transform: scale(1, 1); }
  50%      { transform: scale(1.004, 1.012); }
}
#pet.idle { animation: idleBreathe 4.2s ease-in-out infinite; }

/* 从大肥鱼照抄的弹跳 */
@keyframes bounce {
  0%   { transform: scale(1); }
  25%  { transform: scale(.9, .84) translateY(-6px); }
  50%  { transform: scale(1.08, 1.1) translateY(2px); }
  75%  { transform: scale(.97, 1.03); }
  100% { transform: scale(1); }
}
#pet.bounce { animation: bounce .55s cubic-bezier(.34, 1.56, .64, 1); }

@keyframes tilt {
  0%, 100% { transform: rotate(0); }
  35%      { transform: rotate(-6deg) translateY(-2px); }
  70%      { transform: rotate(3deg); }
}
#pet.tilt { animation: tilt .8s ease-in-out; }
```

做完这一步就已经"像大肥鱼"了。

## 四、方案 B：分层立体（在 A 之上叠加）

把 `#pet` 从 `<img>` 换成一个容器，四个图层绝对定位堆叠。**每层都必须是精灵画布的全尺寸**（1024×1024 同一坐标系，直接 `inset:0; width:100%; height:100%` 即可对齐，不需要算位置）。

```html
<div id="pet" class="pet">
  <img class="fx-halo"    src="assets/states/fx/halo.png"    alt="">
  <img class="fx-cast"    src="assets/states/fx/shadow.png"  alt="">
  <img class="fx-body"    src="assets/states/body/idle.png"  alt="赫尔墨兹">
  <div class="fx-gloss"></div>
  <img class="fx-contact" src="assets/states/fx/contact.png" alt="">
</div>
```

```css
.pet {
  position: relative;
  width: 350px;
  height: 350px;          /* 正方形，等于画布比 */
  transform-origin: 50% 96%;
  transition: transform .18s ease-out;
  will-change: transform;
}
.pet > * { position: absolute; inset: 0; width: 100%; height: 100%; display: block; }

/* 1. 背后泛光 */
.fx-halo {
  mix-blend-mode: screen;
  opacity: .55;
  animation: haloPulse 5.2s ease-in-out infinite;
}
/* 2. 落影：随呼吸缩放变淡 */
.fx-cast {
  transform-origin: 50% 95%;
  animation: castPulse 4.2s ease-in-out infinite;
}
/* 3. 主体 */
.fx-body {
  filter: drop-shadow(0 4px 8px rgba(10, 16, 32, .22));
  animation: idleBreathe 4.2s ease-in-out infinite;
  transform-origin: 50% 95%;
}
/* 4. 玻璃高光：用主体 alpha 当遮罩，光只落在人物身上，不会洒到桌面 */
.fx-gloss {
  background: linear-gradient(102deg,
    rgba(255,255,255,0) 34%,
    rgba(255,255,255,.85) 45%,
    rgba(255,255,255,.22) 52%,
    rgba(255,255,255,0) 63%);
  background-size: 320% 100%;
  background-position: 140% 0;
  mix-blend-mode: screen;
  -webkit-mask: url("../assets/states/body/idle.png") center/100% 100% no-repeat;
          mask: url("../assets/states/body/idle.png") center/100% 100% no-repeat;
  animation: sweep 7.5s cubic-bezier(.4,0,.2,1) infinite;
  pointer-events: none;
}
/* 5. 贴地影 */
.fx-contact {
  transform-origin: 50% 95%;
  animation: contactPulse 4.2s ease-in-out infinite;
}

@keyframes haloPulse   { 0%,100% { opacity:.45; transform:scale(.98) } 50% { opacity:.62; transform:scale(1.03) } }
@keyframes castPulse   { 0%,100% { opacity:.92; transform:scale(1) }    50% { opacity:.74; transform:scale(1.035) } }
@keyframes contactPulse{ 0%,100% { opacity:1;   transform:scale(1) }    50% { opacity:.82; transform:scale(1.05) } }
@keyframes sweep       { 0% { background-position:140% 0 } 62% { background-position:140% 0 } 100% { background-position:-60% 0 } }
```

### 光标视差（可选，幅度要小）

```js
window.addEventListener('mousemove', (ev) => {
  const dx = (ev.clientX - window.innerWidth / 2) / (window.innerWidth / 2);
  const dy = (ev.clientY - window.innerHeight / 2) / (window.innerHeight / 2);
  pet.style.transform =
    `perspective(900px) rotateY(${dx * 3.2}deg) rotateX(${-dy * 2.2}deg)`;
});
```

超过 5 度就假了，2~3 度刚好。

## 五、必须注意的四个坑

1. **别给容器加 `backdrop-filter`**。它会创建 fixed 包含块，里面所有 `position:fixed` 元素（气泡、徽标）的坐标基准会从窗口变成容器，位置全乱。要做毛玻璃就放 `::before` + `z-index:-1`。
2. **`pointer-events`**：容器 `#pet` 必须 `none`，只让主图或一个透明热区 `auto`，否则 350×350 的方块会挡住桌面图标点击。
3. **mask 路径**是相对 **CSS 文件**的，不是相对 HTML。写在 `app/renderer/style.css` 里就要 `../assets/states/body/idle.png`。
4. **不要给这些层加 `filter: blur()` 之类的逐帧滤镜**。透明窗口下每帧重新合成 blur 很吃 GPU，笔记本风扇会吵。落影已经在 PNG 里烘焙好了，直接用。

## 六、验收标准

- [ ] 浅色壁纸：人物边缘无白边、无灰边
- [ ] 深色壁纸：无白楔子、无白斑（原图这两个问题已修，接入后应验证）
- [ ] 呼吸 4 秒一轮，幅度肉眼要"几乎看不出在动，但停下来会觉得死"
- [ ] 拖窗口时立绘不抖、不变形
- [ ] 关掉 `fx-*` 三层后，剩下的画面与大肥鱼观感一致
