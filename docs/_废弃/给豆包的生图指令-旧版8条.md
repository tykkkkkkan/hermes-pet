# 给豆包的生图指令（可直接复制）

> 目标：基于现有的 01 号站姿图，生成同一个角色的 7 个新姿势。
> 关键原则：**不是"再画一个类似的角色"，是"让同一个角色换个动作"**。

---

## 一、操作步骤

1. 豆包 → 图片生成
2. **上传参考图**：`01-站姿-常驻形象.png`（桌面「赫尔墨兹素材-立体化」文件夹里）
3. 比例选 **1:1（正方形）**
4. 粘贴下面的【通用角色描述】+【姿势】整段
5. 一次生成 4 张，挑最像的那张
6. **挑不出来就别凑合**，改提示词重来

## 三、构图要求（8 条都用这段）

```
构图：全身正面像，从帽顶到鞋底完整入画，人物居中，身高约占画面80%，
脚底接近画面底部但留一点空隙，头顶上方留白。
背景：纯洋红色 #FF00FF 的纯色背景。绝对不要渐变、不要阴影、不要地面、
不要光斑、不要边框、不要文字、不要任何背景元素。正方形构图。
```

> **为什么要洋红背景**：她的衣服和头发都是白/银，白底抠不干净（边缘会糊在一起）；洋红与银白对比极强，抠像最干净。生成后不要自己处理背景，原图给我，我这边有脚本抠。

## 五、如果生成的图不对，这么改

| 问题 | 原因 | 怎么救 |
|---|---|---|
| **人物不像原图**（发色、衣服变了） | 参考图权重太低，AI 自由发挥 | 提示词开头加一句「**必须100%保持上传图中的人物外形，不得改动发型、服装、配色**」；或换"图生图"模式、把相似度调高 |
| **姿势没变**，还是原图那样站着 | 参考图权重太高，AI 在照抄 | 强调「**只需要参考人物的长相和穿着，姿势必须完全按我说的重新画**」 |
| **背景不是纯洋红**，有渐变或阴影 | 模型对纯色背景执行不稳 | 别自己抠，原图发我。我改用白底抠图，或者你换「纯绿色 #00FF00」再试一次 |
| **手和道具糊了**（AI 画手的通病） | 常见缺陷 | 直接重抽，别修。手糊的图在桌面上放大更明显 |
| **画布不是正方形** | 比例设置 | 生成时明确选 1:1 |
| **八张脸越出越不像** | 角色一致性漂移 | 这正常。**固定只用 01 号当参考图**，不要拿新生成的图去当参考（会越漂越远） |

## 六、必须守住的三件事

**一、只用 01 号当参考图。** 不要"用上一张生成的成功图去生成下一张"——那样误差会累积，第 8 张会完全变成另一个人。

**二、一次只改姿势，不改任何别的描述。** 通用角色描述那段，8 次必须逐字相同。改一个字，形象就可能偏。

**三、不要自己抠图、不要自己裁、不要自己压缩。** 原图给我，我这边有专门的管线（`tools/build-pet-3d.js`）做抠底、对齐、立体化。你处理过的反而会破坏它依赖的判据。

## 八、顺手记一下：她的三个"身份特征"

这些是辨认她的关键，也是 AI 最容易画丢的地方。出图后对照检查：

| 特征 | 丢了的后果 |
|---|---|
| **帽子 + 帽子两侧的小羽翼** | 最容易丢。丢了就不像她，只剩一个银发少女 |
| **背后的白色翅膀** | 容易被省略或被画成装饰图案 |
| **手里的书 + 平板** | 这是她的"工具"，丢了她就从"秘书"变成普通女孩 |

三样都在，才是赫尔墨兹。
