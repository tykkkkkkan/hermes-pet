# Live2D 分层素材规范（Hermes Pet）

> 目的：把现有的单层 Q 版执事立绘，改造成 Cubism 能绑骨骼的分层 PSD。
> 这份文档既是给画师的需求书，也是 AI 分层重绘的验收标准。

## 一、为什么必须分层

Live2D 不是给整张图加滤镜，而是**把每张图层当一块可以独立弯折的皮**。引擎靠「眼睛层单独闭、嘴巴层单独开、头发层单独晃」来制造活的错觉。

单层图喂进去只能整体拉伸，一扭头就破。所以分层是硬前提，不是可选项。

## 二、图层清单

按绘制顺序从后到前排列，**同一行内的层不能合并**。

| # | 图层名 | 必需 | 说明 |
|---:|---|---|---|
| 1 | `wing_back_L` / `wing_back_R` | ✅ | 背后小翅膀，左右分开（要做滞后摆动） |
| 2 | `hair_back` | ✅ | 后发（被身体遮住的部分也要画满） |
| 3 | `body` | ✅ | 躯干 + 衬衫，不含手臂 |
| 4 | `skirt_far` | ✅ | 裙摆远侧一片（做裙摆错位） |
| 5 | `arm_L_upper` / `arm_L_fore` / `hand_L` | ✅ | 左臂三段（上臂/前臂/手） |
| 6 | `arm_R_upper` / `arm_R_fore` / `hand_R` | ✅ | 右臂三段 |
| 7 | `prop_book` | ✅ | 棕色书（独立层，可单独晃） |
| 8 | `prop_tablet` | ⬜ | 平板（若某状态没有则留空层） |
| 9 | `skirt_near` | ✅ | 裙摆近侧一片 |
| 10 | `neck` | ✅ | 脖子（转头时露出的部分） |
| 11 | `face_base` | ✅ | 脸部底色 + 腮红，**不含五官** |
| 12 | `brow_L` / `brow_R` | ✅ | 左右眉各一层 |
| 13 | `eye_L_white` / `eye_R_white` | ✅ | 眼白 |
| 14 | `eye_L_iris` / `eye_R_iris` | ✅ | 瞳孔（做视线移动） |
| 15 | `eye_L_lid` / `eye_R_lid` | ✅ | 上眼睑（做眨眼，**闭眼要靠这层盖下来**） |
| 16 | `mouth` | ✅ | 嘴（做口型/表情） |
| 17 | `hair_front_L` / `hair_front_R` | ✅ | 前刘海，左右分开（做出入画呼吸） |
| 18 | `hat` | ✅ | 贝雷帽 + 徽章 |
| 19 | `wing_front_L` / `wing_front_R` | ⬜ | 头侧小翅膀（若有） |

**最低可动集合**（想先跑起来可以只做这些，共 12 层）：
`body`、`neck`、`face_base`、`brow_L`、`brow_R`、`eye_L_lid`、`eye_R_lid`、`eye_L_iris`、`eye_R_iris`、`mouth`、`hair_front_L`、`hair_front_R`

有这套就能做：眨眼、视线跟随、说话口型、眉毛表情、头部转动。

## 三、画布与对齐

| 项 | 要求 |
|---|---|
| 画布 | 2048 × 2048，**所有图层同一尺寸、同一原点** |
| 位置 | 角色居中偏下，头顶留 ~10% 余量，脚底贴近底边 |
| 分辨率 | 不低于 3000px 高（导出时可缩到 2048 画布） |
| 色彩 | sRGB，带透明通道 |
| 对齐 | 每层都在**同一张 2048 画布上的绝对位置**画好，不要各自裁剪 |

> 这条最容易出错：如果每层都「裁到内容边界」再导出，图层间的相对位置就丢了，绑骨骼时要手工对位，非常痛苦。

## 四、过画（Overscan）

形变时图层会移动、旋转，原来被别层盖住的地方会露出来。所以：

- 凡是被遮挡的部件，**要多画 8–16px 的延伸**（头发盖住的额头要画满、手臂盖住的侧腰要补全）。
- 眼睛层要画到比眼白更大一圈，闭眼时才不会露缝。
- 裙摆内侧、袖子内侧、脖子根部，都要补画。

**判断标准**：把任一图层单独显示并平移 ±10px，画面不应出现透明空洞。

## 五、导出规范

```text
格式：PSD（单个文件，所有层）
图层命名：严格用上表的英文名，层名即参数名
图层顺序：与上表 #1 → #19 一致（1 在最底）
不要：图层文件夹嵌套超过 1 层、图层样式/蒙版/调整层（Cubism 不认）
可以：图层内用普通栅格，不用智能对象
附带：一张合并的参考图（合并预览.png），用于比对
```

## 六、三条产出路径

| 路径 | 怎么做 | 成本 | 质量 | 风险 |
|---|---|---|---|---|
| **A. 画师约稿** | 把本文档发给画师，要求按层交付 PSD | ¥300–1500（Q 版拆分立绘行情） | 最好，边缘干净 | 需沟通，周期 3–7 天 |
| **B. AI 分层重绘** | 用现有立绘作参考图，逐部件生成再合成 | 消耗图像生成额度，多轮修图 | 中等，边缘/一致性需人工修 | 一致性难保证，可能反复 |
| **C. 手动抠图分层** | Photoshop 里把现有立绘拆层 + 补绘遮挡区 | 0 元，纯工时 | 取决于补绘水平 | 工作量大，遮挡区要重画 |

**建议**：先走 C 的简化版——只拆「最低可动集合」12 层，用现有立绘抠图 + 简单补绘。这样能最快看到自己的角色动起来，跑通之后再决定要不要投入 A。

## 七、验收标准

分层素材交付后，用这三条检查：

1. **无空洞**：任一图层单独 ±10px 平移，不出现透明洞。
2. **无错位**：所有图层叠回去，与原本的合并图逐像素一致（±2px 内）。
3. **可独立操作**：单独隐藏 `eye_L_lid` 只影响左眼，不影响其他。

三条全过，才能进 Phase 2 绑骨骼。

## 八、FREE 版限制对照

Cubism Editor 免费版的上限，本角色在这个范围内：

| 限制项 | 免费版上限 | 本角色预估 |
|---|---|---|
| 纹理 | 1 张 2048px | 1 张（全部图层合成一张图集） |
| ArtMesh | 100 | 约 50–70 |
| 动作参数 | 30 | 约 15–20 |
| 变形器 | 50 | 约 30–40 |
| 部件 | 30 | 约 20 |

超出后**无法保存/导出**，所以部件数要克制，别做太细的分层。
